# 株トレード防衛 Ver.1.5.0 RC1

## 主な変更（Ver.1.4 RC1から）
- **4口座分の画像を一度に選択**し、画像ごとに登録先口座を明示的に指定可能
- 同一銘柄の信用建玉でも、**口座をまたいでOCR結合しない**（画像ごとに口座グループ分割）
- OCR確認候補ごとに口座選択・修正。保存時に口座別件数を示して再確認
- 既存の建玉上書き・重複判定 `LotCore` は継続。損切り価格をOCR更新で上書きしない
- 保証金のOCR表示も口座別に分離。ただし**口座保証金には自動保存しない**
- Service Workerのキャッシュ版を更新し、新しい`batch-core.js`をオフライン対象に追加
- 公開コードに証券口座の実データやスクリーンショットを含めない

## 操作
1. 「口座・建玉」で必要な口座（例：4口座）を登録
2. 「画像取込」で複数画像を選択
3. **各画像の所属口座を選択**。同じ口座の価格・株数画像には同じ口座を設定
4. OCR実行後、各候補の銘柄・価格・株数・口座を確認
5. 確定登録前に、表示された口座別件数を確認。過去の検証用画像は現在データとして保存しない

## 制約
- 画像から口座名を自動推測しません。誤口座を選ぶと誤登録されるため必ず確認が必要です。
- OCRの既知銘柄カタログは一部のみ。他の銘柄や現物画面全般の認識は未検証です。
- 同一銘柄の集約建玉と建日別明細を混同しません。識別できない場合は保留します。
- SBI実口座の追証判定と、iPhone実機の4口座一括取り込み精度は未照合です。
- 個人データは端末内に保存。公開GitHubには絶対に実口座情報を入れないでください。
