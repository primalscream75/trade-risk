# 株トレード防衛 Ver.1.4.0 RC1

## 開発内容
- 建日・明細ID（任意）を建玉登録フォームとOCR確認フォームへ追加
- 同一口座・同一銘柄・同一売買区分の複数建玉を、明細IDで識別して登録・更新
- 明細ID不明の集約建玉と明細別建玉を混同しない。二重計上の危険がある場合は**保留**
- 同じ取り込みセットで重複した候補を保留
- 口座の異なる同一銘柄を混同しない。既存の撤退価格は更新時に維持
- 追証概算やデータ鮮度の従来の制限は維持

## 制約（重要）
- SBIスクリーンショットから建日ごとの識別子を自動生成する機能は **未実装**。OCRに建日がない場合は任意で手入力
- SBIの同一銘柄が複数建日の場合、画像によっては一覧が集約されている。集約値と個別明細を同時に登録しないこと
- 現物OCRの汎用性・他銘柄への認識精度は未検証。既知銘柄以外は手動追加
- 4口座の取り込み・保存・復元はiPhone実機未検証
- 個人の画像、資産・建玉は公開リポジトリに入れない

## 更新手順
旧版でバックアップを取得し、ファイルをGitHubリポジトリ直下に上書き。旧保存キー `trade-risk-portfolio-v1` は変更しない。保存済み建玉には `lotKey` を付加せず、そのまま旧集約データとして扱う。

## テスト
`node test-v13.js` と `node test-v14.js`。JavaScriptファイルには `node --check` を実施。
