# 株トレード防衛 Ver.0.9.4（価格OCR・上下段の分離）

## 主な変更
- SBI信用建玉「現在値／平均建単価」を **上段と下段に分けて** それぞれOCR（PSM 7）。
- 数字の右にある「円」を読まないよう数値領域の右端を除外。
- 損益欄の上段だけを別OCRして評価損益額を抽出。
- 数値として不適切なOCR結果は無理に修正せず空欄（要確認）にする。
- 従来の口座・建玉保存形式とバックアップ機能は維持。ユーザーの実データは同梱しない。

## 検証
- 提供済みのSBI画像 **IMG_6967.png** をこの切り出し座標で画像加工し、ローカルTesseract（英語・psm7）で確認：
  - フジクラ：2,835.5／5,621.02／-13,259,413
  - GO：2,769／3,228.42／-3,602,293
- **IMG_6968.png** の同じ座標も数字行の切り出しを確認。これは数量画面のため、価格用認識はかけない。
- JavaScript単体テスト / 構文チェックはパッケージに付属。

## 注意
- iPhone（ブラウザTesseract.js + 日本語・英語辞書）での結果はまだ未確認。ローカルエンジンでの検証は、そのままiPhoneでの認識精度保証にはならない。
- 画像のレイアウトや文字サイズが異なると座標がずれる。評価額・株数の一致確認および手動確認必須。
- 自動取込結果はまず保存しないで、原本スクリーンショットと照合。
- 旧版アプリに保存したデータは公開前にバックアップすること。OCR画像は端末内処理、初回エンジン・辞書ダウンロードはインターネット接続が必要。
