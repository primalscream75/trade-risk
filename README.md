# 株トレード防衛 Ver.1.1.0-rc1

## 今回の実装
- **統合ダッシュボード**：複数口座の純資産・信用建玉・撤退リスク・同時逆行損失を横断集計
- 口座別、テーマ別の建玉時価・撤退リスク・急落試算
- SBIの入力済み保証金情報を使う口座別の維持率試算（登録建代金と一致したときのみ）
- 損切り未設定・逆方向・建代金不一致の未判定警告
- 口座別に取得したデータの最新更新時刻を表示（旧データは不明と明記）
- 既存の `trade-risk-portfolio-v1` 保存データを読み込み、**キーやデータ構造を置換しない**
- ローカル計算のみ。個人の口座データ、OCR画像、APIキーは同梱しない

## 使い方
1. 旧バージョンの「設定」→「バックアップJSONを書き出す」でバックアップを保管（可能であれば）
2. ZIPを解凍し、ファイルをリポジトリ直下へ上書き。READMEは任意。削除する必要のある旧ファイルはない
3. iPhoneのキャッシュ更新後、ヘッダーが `1.1.0-rc1` であることを確認
4. 「口座・建玉」で複数口座・建玉を登録／確認
5. 「統合ダッシュボード」で全口座／口座別を切り替えて試算

## 計算の注意点
- 建玉金額は信用売りも絶対値で合算。信用取引の元本と評価額、担保評価は別項目です
- 撤退リスクは現在値から設定した撤退価格までの不利方向の値幅に株数を掛けた値。設定なし・突破済は「未判定」
- 同時逆行はすべての銘柄が指定の割合だけ**それぞれ不利方向に**動く人工的なストレステスト
- テーマは1銘柄1テーマの単純集計で、テーマ相関や重複を自動推計しません
- 保証金試算は概算で、すべての信用建玉を登録している場合のみ計算。SBI実際の追証判定を代替しません
- 同じ担保を現物株と代用評価で重複してショック評価する可能性に留意
- 最新株価の自動取得はありません。古い保有・評価額データから現在の判断をしないでください
