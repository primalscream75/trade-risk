# 株トレード防衛 Ver.1.0.0-rc2 (OCR採用ロジック修正)

## 変更点
- 現在値・建単価をそれぞれ独立して採用。片方が空欄でも、もう一方を破棄・取り違えない。
- OCR候補の数値形式をチェックし、円記号・空欄・改行を安全に処理。
- 評価損益のマイナス記号が読めない場合は金額を自動登録しない（空欄として確認）。
- 価格欄・評価損益欄の再試行切り出しパターンを拡充。
- 再試行しても認識できない値は手動確認可能。
- キャッシュをrc2へ更新し、GitHub Pages更新がiPhoneに反映されやすいようにした。

## 制限事項
- SBIスクリーンショットの全形式・複数明細へ未対応。
- OCRが読み取れた数値も必ず原画像と照合してください。
- OCRエンジン初回起動時はネット接続が必要です。
- 口座情報や画像をGitHubへアップロードしないでください。

## 検証
`node test-sbi-roi.js`, `node test-sbi-price.js`, `node test-sbi-retry.js`, `node test-sbi-independent.js` ほかを実行。
