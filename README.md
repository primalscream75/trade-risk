# 株トレード防衛 Ver.1.3.0 RC1

## 追加・修正
- 口座別のデータ信頼性監査：建玉更新24時間、信用建玉の全件照合、保証金情報鮮度、撤退価格未設定
- 「SBIの全信用建玉と照合済みにする」操作を追加（画面を確認した場合のみ）
- 建玉の編集・追加・削除・OCR更新で照合済み状態を自動解除
- 保証金入力更新時刻を独立保存。旧バージョンで時刻不明なデータは未判定
- 追証・維持率の試算は、建代金一致・全件照合・保証金更新24時間以内の場合にだけ表示
- プロジェクトの表示バージョンとPWAキャッシュを更新

## 保持データ
旧保存キー trade-risk-portfolio-v1 を維持。既存データは破棄しない。
新規フィールド（reconciledAt、marginUpdatedAt）は、旧データでは未設定扱い。
既存データを移行で勝手に「照合済み」にしない。

## 追証判定について
SBIの公式維持率は、建単価の端数処理、金利、経費、代用掛目、受渡未到来の決済損益などでアプリ概算と相違する。
通常の追証基準20%と、新規建余力判断の基準を混同しない。
アプリは信用新規建余力を算出しない。追証の実際の有無・金額はSBI画面を確認。

## 更新方法
既存の資産・建玉バックアップを保存した後、ZIP内のファイルをGitHubリポジトリ直下に上書き。個人のスクショや口座データはアップロードしない。
